# ZeroGroup Website



## 📌 Proje Hakkında



Bu proje, ZeroGroup şirketi için geliştirilmiş kurumsal web sitesidir.

Şirketin hizmetlerini tanıtmak ve kullanıcıya bilgi sunmak amacıyla hazırlanmıştır.



---



## 🚀 Özellikler



* Ana sayfa

* İnsan Kaynakları (IK)

* Lojistik hizmetleri

* Organizasyon hizmetleri

* Temizlik hizmetleri



---



## 🛠️ Kullanılan Teknolojiler



* HTML5

* CSS3

* JavaScript (Vanilla JS)



---

```

file/
```

---



## ⚙️ Kurulum ve Çalıştırma



Projeyi çalıştırmak için:



1. Bu repository'yi indir:



```

git clone https://github.com/EsraNisa/zerogroup-website.git

```



2. Klasöre gir:



```

cd zerogroup-website

```



3. `index.html` dosyasını tarayıcıda aç
